# PawCare Android App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build PawCare, a native Android veterinary clinic management application in Kotlin and Jetpack Compose with Firebase Auth and Cloud Firestore, supporting Pet Owner and Clinic Admin roles with 5 core features within the 5-week course timeline.

**Architecture:** Single-Activity MVVM architecture using Jetpack Compose Navigation, Material 3 UI, and `StateFlow` backed by `sealed interface UiState<out T>`. Cloud Firestore provides real-time snapshot streams and offline persistence, with an atomic `booked_slots` lock document preventing double-booking and single-field queries guaranteeing zero composite index crashes.

**Tech Stack:** Kotlin 2.0+, Android Gradle Plugin, Jetpack Compose (BOM 2024.10+), Material Design 3, Navigation Compose, AndroidX Lifecycle (`collectAsStateWithLifecycle`), Firebase Android BOM (Auth, Cloud Firestore), Kotlinx Coroutines, JUnit 4/5.

**Spec:** `docs/superpowers/specs/2026-11-11-pawcare-design.md`

## Global Constraints

- Platform: Native Android, `applicationId = "com.pawcare.app"`, `minSdk = 26`, `targetSdk = 35` (native `java.time` support).
- UI Language: Indonesian (labels, placeholders, snackbars, and dialog copy).
- Security & Secrets: Never commit `google-services.json` or private credentials to git; provide `app/google-services.json.example` and documentation in `README.md`.
- Architecture boundaries: Pure separation of `ui/`, `viewmodel/`, `data/model/`, `data/repository/`, `di/`, and `util/`.
- Course Deliverable alignment: Clean incremental Git commits (`feat:`, `fix:`) reaching 10–15+ commits, runnable on Android Emulator/device, APK packaging, and complete error/empty/loading UI states.

## Review Focus

1. **Past Date or Past Hour Booking Attempt:** An owner attempts to pick a date before today or a past hour on today's date; the UI must disable those chips/dates and ViewModel validation must reject submission.
2. **Concurrent Double-Booking Race:** Two owners attempt to book the identical date and time slot simultaneously; Firestore transaction on `booked_slots/{slotKey}` must allow exactly one and return a user-friendly conflict error to the second.
3. **Admin Escalation on Client Register:** A malicious client sends `role: "admin"` during user registration; Firestore security rules and `AuthRepository` must strictly force `role = "owner"`.
4. **Deleting a Pet with Active Appointments:** An owner attempts to delete a pet that has `PENDING` or `CONFIRMED` appointments; deletion must be blocked with an informative dialog to avoid orphaned slots.
5. **Missing Vaccine Name for Vaccination Service:** An admin attempts to complete a vaccination appointment without filling in `vaccineName`; form validation must mark the field as required and block saving.
